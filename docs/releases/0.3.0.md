# Pocket Lens 0.3.0

## Español

- Botones para encender y apagar la pantalla física durante una sesión, con los atajos Alt+O y Alt+Mayús+O.
- Gestor de archivos con PC y celular lado a lado, arrastrar y soltar, carpetas, copiar, mover, renombrar y eliminar.
- Progreso, cancelación, conflictos y verificación SHA-256 de transferencias. Los APK se copian como archivos.
- Actualizaciones firmadas desde la app: solo versiones estables, descarga bajo demanda e instalación al confirmar.
- Conserva perfiles, imágenes y preferencias de versiones anteriores.

La versión 0.2.0 requiere instalar esta versión manualmente una vez para habilitar el actualizador. El gestor accede al almacenamiento compartido que Android permite a ADB; no necesita root. En Android el borrado es definitivo y requiere confirmación. En Windows se utiliza la Papelera; un fallo no se convierte en borrado permanente.

## English

- In-session physical-screen on/off buttons and Alt+O / Alt+Shift+O shortcuts.
- Dual-pane PC/phone file manager with drag and drop, folders, copy, move, rename and delete.
- Progress, cancellation, conflicts and SHA-256 verification. APK files are copied without installation.
- Signed in-app updates: stable releases only, user-initiated download and confirmed installation.
- Existing profiles, artwork and preferences are retained.

Install this version manually once when upgrading from 0.2.0 to enable future in-app updates. File access is limited to shared storage available to authorized ADB; root is not needed. Android deletion is permanent and confirmed. Windows deletion uses the Recycle Bin and never silently falls back to permanent deletion.

Windows 10/11 x64; bundled official scrcpy 4.1. See the repository's validation matrix for actual hardware coverage.
