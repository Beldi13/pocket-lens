# Contributing / Contribuir

Issues and pull requests are welcome. Please describe the problem, expected result, Windows and Android versions, scrcpy version and reproducible steps. Remove device serials, IPs, pairing codes, personal recordings and credentials from attachments.

Las contribuciones son bienvenidas. Describe el problema, pasos y versiones. No publiques direcciones, números de serie, códigos ni grabaciones personales.

Use the development and validation commands in README.md. Include meaningful tests for identity, transport or process-lifecycle changes. UI strings must be provided in Spanish and English. Keep scrcpy/ADB process arguments structured; do not add shell execution or global process termination. Update third-party notices and pinned hashes when upgrading the vendor distribution.

Avoid mixing unrelated features into a patch. Hardware checks requiring unavailable phones must be recorded as pending, not marked as passed. Camera, embedded video and virtual-display work should start with an issue discussing the intended design.

Contributions are submitted under the project's MIT license. Third-party code and assets require compatible attribution and licensing.
